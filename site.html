My Experiences

PW2 ENERGIA

IoT development and Data analysis

Development of the IoT control server monitoring photovoltaic plants and analysis of data with SQL, Python, JavaScript, HTML and CSS. For the visualization interface we used TABLEAU. Finally, I was able to acquire the data and process raw data to be stored in a postgreSQL database and processed by using Apache Airflow to automate the routines every 10 minutes.

EDF Paris-Saclay

Data analysis

Software development for BESS with Python using a PostgreSQL database. We used the GitLab repository to version the code and automate the compatibility tests within a CI/CD process. I was responsible for integrating the database with the software with the aim of validating the battery ageing model. Finally, the version of the software responsible for the ageing model was validated.

Institute SuperGrid

Firmware development

Led the development of embedded systems applications using the STM32 family of microcontrollers, programming in C/C++ and leveraging the FreeRTOS real-time operating system. Designed and implemented robust communication protocols, including MODBUS over TCP/IP and UART, to enable reliable and efficient data exchange between devices. Focused on performance optimization, real-time task scheduling, and system stability in resource-constrained environments.

RAITec

IoT development

Designed photovoltaic (solar energy) systems and led the development of an IoT project based on the ESP32 microcontroller. The system was programmed using C++ for the embedded back-end and utilized HTML and CSS for the web-based front-end interface. Focused on integrating hardware and software components to enable remote monitoring, control, and real-time data visualization of solar energy generation.
